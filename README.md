# Asteroid Game

Ein selbst entwickeltes 2D-Space-Shooter-Spiel, inspiriert vom klassischen **Asteroids**-Gameplay.

Das Projekt wurde mit **Unity und C#** entwickelt und dient gleichzeitig dazu, praktische Erfahrungen in Spieleentwicklung, Programmierung und dem Umgang mit Unity zu sammeln.

## Steuerung

| Taste     | Funktion               |
| --------- | ---------------------- |
| **W**     | Vorwärts beschleunigen |
| **A / D** | Raumschiff drehen      |
| **Space** | Schießen               |

## Ziel des Projekts

Das Projekt entstand als praktische Übung, um die Entwicklung eines vollständigen kleinen Spiels mit Unity und C# umzusetzen.

Dabei lag der Fokus nicht nur auf dem fertigen Spiel, sondern auch darauf, typische Bestandteile einer Spieleentwicklung selbst zu programmieren und miteinander zu verbinden.
